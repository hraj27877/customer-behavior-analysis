# 🛍️ Customer Shopping Behavior Analysis

Analyzing 3,900 customer transactions to understand shopping patterns, spending habits, and what drives customer loyalty 📊

---

## 🧰 Tools Used

🐍 Python (pandas) &nbsp;•&nbsp; 🗄️ PostgreSQL &nbsp;•&nbsp; 📈 Power BI

---

## 📂 What's Inside

| File | Description |
|---|---|
| `customer_shopping_behavior.csv` | Raw dataset |
| `Customer_Shopping_Behaviour_Analysis.ipynb` | Data cleaning & feature engineering |
| `Sql_queries.sql` | Business questions answered in SQL |
| `customer_behavior_dashboard.pbix` | Power BI dashboard |
| `Customer_Shopping_Behavior_Analysis.pdf` | Full report |

---

## 🔍 What I Did

- 🧹 Cleaned the data & filled missing review ratings by category
- 🏷️ Standardized column names
- 👥 Grouped customers by age using quartiles
- 🗃️ Loaded clean data into PostgreSQL
- ❓ Answered 10 business questions with SQL
- 📊 Built an interactive Power BI dashboard

---

## ✨ Key Findings

- 👨 Male customers generated ~2x the revenue of 👩 female customers
- 🔁 Most customers are repeat/loyal buyers, not new ones
- 🏷️ Some products (Hats, Sneakers, Coats) rely heavily on discounts
- 🚚 Express shipping customers spend slightly more than Standard
- 💳 Only ~27% of customers are subscribers

---

## 💡 Recommendations

- 📣 Promote subscription benefits
- 🎁 Build loyalty rewards for repeat customers
- 💰 Review discount-heavy product pricing
- ⭐ Market top-rated products more
- 🎯 Target high-revenue age groups
